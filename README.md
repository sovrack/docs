# Sovrack Documentation

Official documentation for **Sovrack** — The Open-Core Deployment & Orchestration Platform.

Visit the live documentation at [docs.sovrack.com](https://docs.sovrack.com).

## 📚 Structure

- `docs/getting-started/`: Installation, system requirements, and first deployment.
- `docs/architecture/`: Agentless SSH architecture, Nixpacks build engine, and proxy mechanics.
- `docs/guides/`: How-to guides for Node.js, Next.js, Python, PostgreSQL, domains, and Let's Encrypt.
- `docs/cli/`: Reference manual for the `sovrack` CLI tool.

## 🚀 Local Development

```bash
npm install
npm run dev
```
